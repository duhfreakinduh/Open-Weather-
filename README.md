# Open Weather Dashboard

A simple open-source weather dashboard built with:

- Leaflet
- OpenStreetMap
- Open-Meteo

## Features

- Search for any city
- Use your current location
- Click on the map to get weather
- Current weather conditions
- 7-day forecast
- Small embedded map
- Clean responsive interface

## Live Demo

https://duhfreakinduh.github.io/open-weather-dashboard/

## How to Use

1. Type a city name in the search bar
2. Click **Search**
3. Or click **My location**
4. Or click anywhere on the map
5. View current weather and forecast

## Tech Stack

- HTML
- CSS
- JavaScript
- Leaflet
- OpenStreetMap tiles
- Open-Meteo API

## Notes

This project uses free and open tools for map tiles and weather data.
